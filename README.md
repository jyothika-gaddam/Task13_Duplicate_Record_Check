# Task 13 - Duplicate Record Check

## 📌 Project Overview

This project focuses on identifying duplicate records in a dataset using Google Sheets.

The dataset was reviewed to detect duplicate rows, document the findings, and prepare a cleaned dataset for further analysis.

## 🎯 Objectives

- Identify duplicate records
- Check the dataset for repeated rows
- Document the duplicate record findings
- Remove duplicate records where applicable
- Prepare a cleaned dataset

## 🛠️ Tools Used

- Google Sheets
- CSV Dataset
- Data Cleanup
- Duplicate Record Check
